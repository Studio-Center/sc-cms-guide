Setting up a new site

Once sc-cms is installed, open /admin on your site (for example https://www.example.com/admin). On a fresh install, it opens Set up your site:

Field
Site name Shown in the site header and page titles. You can change it later.
Your name, Email Your Administrator account.
Password At least 12 characters.

Create site creates the site and signs you in. Setup runs only once; after that, /admin goes to the sign-in page.

Run setup before sharing the address

Until setup is done, whoever opens /admin first becomes the Administrator. Run it straight after installing.

Your first ten minutes

Section titled “Your first ten minutes”
  1. Settings → Site: check the site name, and set the Primary domain (such as www.example.com).
  2. Settings → Public site: while you build, tick Ask search engines not to index this site. Untick it at launch.
  3. Pages & Design → Themes: pick a theme, then adjust its colors and fonts. See Design.
  4. Content → Pages: create a Home page, publish it, then set it as the Home page under Settings → Public site. Until then, the home page shows the latest posts.
  5. Pages & Design → Navigation: add your pages to the menu.
  6. People & Access: invite your team.
  7. Ask whoever runs the server to set up email (so invitations arrive) and backups.
