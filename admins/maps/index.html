Location map

The Location map plugin shows your locations on a map that visitors can move and zoom, with a list underneath giving each address, contact details, and “Get directions” links to OpenStreetMap or Google Maps. You don’t need a Google account or an API key.

Turn it on

Section titled “Turn it on”

Go to Extensions, open Location map, approve its permissions, and install it. See Extensions for how plugins work.

Add locations

Section titled “Add locations”
  1. Under Extensions → Location map → Locations, fill in Add or change a location: a short code (such as main-office), a name, the address, and the latitude and longitude.
  2. To find the latitude and longitude, right-click the place on openstreetmap.org and choose Show address, or right-click it in Google Maps and click the numbers at the top of the menu to copy them. You can paste both numbers, separated by a comma, into the Latitude box.
  3. To change a location, save it again with the same code, filling in every field.

Groups (such as “stores” or “europe”) let a map show only some locations and give their markers a color. Add the group first, then type its code in a location’s Groups box.

Put a map on a page

Section titled “Put a map on a page”

Add a Location map block in the editor. Choose a group (or leave it empty for every location), a heading, and the height. Leave Zoom at 0 to fit all locations, or set a zoom and a center.

The list under the map is what screen-reader users get, and so do visitors whose browser can’t show the map, so it’s always there. If you turn Show the list off, it’s hidden from view only once the map has loaded.

Changes to locations show on your pages straight away.

Map pictures (tiles)

Section titled “Map pictures (tiles)”

By default the map uses OpenStreetMap’s free tile server. It’s fine for ordinary sites, but it isn’t meant for heavy use and has no guarantee. For a busy site, sign up with a tile provider (such as MapTiler, Stadia Maps, or Thunderforest), paste the address it gives you into Map tiles address in the plugin’s settings, and add its credit to Map credit. Always keep the OpenStreetMap credit.

Visitors’ browsers fetch the map pictures from the tile provider directly, so the provider sees their IP address. The map is the one feature that adds a script to your public pages, and only to pages that contain a map.
