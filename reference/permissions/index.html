Roles and permissions

Roles are bundles of permissions. Give people the built-in roles, or create your own.

Permission Admin Editor Author Designer Developer Member
General
Open the admin ✓ ✓ ✓ ✓ ✓
Change site settings and domains ✓
View the activity log ✓
People
Invite, edit, and suspend people ✓
Create and edit roles ✓
Content
Create content ✓ ✓ ✓
Edit their own content ✓ ✓ ✓
Edit any content ✓ ✓
Publish and schedule content ✓ ✓
Delete content ✓ ✓
View members-only content ✓ ✓
Media
Upload media ✓ ✓ ✓ ✓ ✓
Edit and delete any media ✓ ✓ ✓ ✓
Design
Change global styles and templates ✓ ✓ ✓
Use developer mode (custom code) ✓ ✓
Extensions
Install and configure extensions ✓

Staff with admin access can always read members-only pages.

The Administrator role always has every permission, and can’t be edited. The Member role appears once memberships are used.
