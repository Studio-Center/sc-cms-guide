Images and files

Media holds every image and file on the site. Upload once, then use it on as many pages as you like.

Uploading

Section titled “Uploading”

Drag files from your computer anywhere onto the media library page, or choose Choose Files under Upload files. You can upload several at once. They appear in the library as soon as they’re done, without the page reloading, and each has an open it link. You can also upload while editing: the Image and Gallery blocks let you pick or upload images.

Kind Accepted
Images JPEG, PNG, GIF, WebP, AVIF, SVG
Video MP4, WebM
Audio MP3
Documents PDF, Word (DOCX), Excel (XLSX), PowerPoint (PPTX), TXT, CSV

Files can be up to 50 MB unless your administrator changed the limit. iPhone photos in HEIC format and MOV videos aren’t accepted. Export them as JPEG or MP4 first, or change your phone’s camera setting to “Most compatible”.

sc-cms makes smaller copies of each photo automatically, so visitors on phones download much less. You don’t need to resize images yourself. Animated GIFs get smaller copies too, which keep the animation and are often a tenth of the size.

Alt text

Section titled “Alt text”

Alt text describes an image for people who can’t see it, such as people using screen readers. It also helps search engines. Describe what matters in the image in a short sentence: “Two volunteers planting a tree in the park”, not “image1.jpg”.

Set it once in the media library, and every Image block using that image picks it up. Images without alt text show an Add alt text button in the library: click it to describe the image there, without opening it. (People who can’t change an image see a No alt text badge instead.) The pre-publish check reminds you too. To fix them all at once, choose Needs a description above the library: it lists every image without alt text, from every folder, with the count. If AI assistance is on, Suggest alt text with AI proposes a description; check it, then choose Save.

Focal point and cropping

Section titled “Focal point and cropping”

On an image’s page:

  • Focal point: click the most important part of the image. When a theme crops the image (say, into a wide banner), it keeps that part in view.
  • Crop: drag to draw the area to keep, then Save. Remove crop undoes it.

Neither changes the original file.

Replacing a file

Section titled “Replacing a file”

Replace file swaps in a new version, for example an updated PDF price list. Every page that uses it shows the new file straight away, with no page edits needed. The replacement must be the same kind of file (an image for an image, a PDF for a PDF).

The old file is kept. The Versions card lists every version with its date, who uploaded it, and its size; the one in use is marked Current. Choose View or Open to check an older version, and Make this the current version to go back to it. The version you replaced is kept too, so you can switch back.

Folders

Section titled “Folders”

The media library opens on its folders. Click a folder to open it; the path at the top shows where you are and takes you back up. Under it are the folders inside, with how many files and folders each holds, and then the files.

  • New folder (top right) creates a folder inside the one you’re in. Folder options renames, moves, or deletes the open folder. Deleting a folder never deletes files: what was in it moves up one level.
  • To move files, tick them (or Select all on this page); a bar appears at the bottom of the window. Choose a folder next to Move to folder, or drag files onto a folder or onto a name in the path. Moving files doesn’t change any page.
  • Files you upload go into the open folder. Searching inside a folder also searches the folders within it; tick Search all files to search the whole library.
  • When you choose an image in the editor, you can browse the same folders. More files load as you scroll down (or choose Load more). Collections still work as before: a file is in one folder but can be in many collections.

Collections

Section titled “Collections”

A collection is a named group of files in an order you choose: “Voice demos”, “Studio photos”, “Press kit”. A file can be in as many collections as you like, and it stays in the library when you take it out of a collection.

  • Create one: under Media → Collections, choose New collection.
  • Add files: in the media library, tick the files, choose a collection, and select Add to collection. You can also add a single file from its own page, under Collections.
  • Reorder or remove: open the collection and drag files into order, or use the ↑ and ↓ buttons; Remove takes a file out. Dragging is available while the collection has up to 500 files.
  • See what’s in it: choose the collection in the menu beside the search box in the media library to see its files in order.

Galleries and audio playlists can show a whole collection. Add a file to the collection and it appears everywhere the collection is shown, with no page edits. A collection’s page lists where it’s shown, under Shown on.

You can’t delete a collection while a published page shows it. Deleting it never deletes its files. People who can upload media can create and change collections; deleting one needs permission to edit and delete any media.

Where is it used?

Section titled “Where is it used?”

Used in lists every page and post using the file, marked Live or draft.

Deleting

Section titled “Deleting”

Delete this file removes it at once. Files used by published content can’t be deleted; remove them from those pages first. Deleting a file also takes it out of every collection.

Who can do what

Section titled “Who can do what”

People who can upload media can change and delete their own uploads. People who can edit and delete any media (Editors, Designers, Administrators) can change anyone’s.
